# Session Bootstrap Workflow

1. Read the project skill for condensed context:
   - `.agents/skills/akgun-panel/SKILL.md`

2. Check the current state of the codebase:
   - Run `npm test` to verify all tests pass
   - Check if dev server is running at `http://localhost:5173`

3. Read the latest session entry in `PROGRESS_LOG.md` (last section only, not the entire file)

4. Review the Next Steps section at the bottom of `CODING_GUIDE.md` (last 15 lines only)

5. Ask the user what they want to work on

> **Token savings:** This workflow reads ~3K tokens instead of ~50K tokens
> from reading all 4 documentation files in full. Read full docs only when
> the specific topic requires it (see the "When to Read Full Docs" table in SKILL.md).
